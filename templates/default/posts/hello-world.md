# 你好，世界！

欢迎来到我的博客！这是使用 Oexa 构建的第一篇文章。

## 关于 Oexa

Oexa 是一个基于 Vue 3 + Vite 的静态博客生成器，特点：

- 🚀 快速 - 基于 Vite 构建
- 🎨 美观 - 使用 MDUI 组件库
- 📝 简单 - 使用 Markdown 写作
- 🔧 灵活 - 支持自定义主题

## 代码示例

```javascript
function hello() {
  console.log('Hello, Oexa!')
}
```

## 开始写作

在 `posts/` 目录下创建 `.md` 文件即可开始写作。

运行 `npm run generate` 生成文章数据，然后 `npm run dev` 预览效果。
