Oexa 是一个基于 Vue 3 + Vite 的静态博客生成器，特点：

- 🚀 快速 - 基于 Vite 构建
- 🎨 美观 - 使用 MDUI 组件库
- 📝 简单 - 使用 Markdown 写作
- 🔧 灵活 - 支持自定义主题
